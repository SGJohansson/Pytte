Faster tab handling, mouse selection and a proper icon.

- `Ctrl+PgDn` / `Ctrl+PgUp` next / previous tab, `Ctrl+1`–`Ctrl+8` jump to a tab, `Ctrl+9` the last one (AltGr characters such as `@ { [ ] }` are left alone)
- `Ctrl+Shift+PgUp` / `Ctrl+Shift+PgDn` move the tab; the order is kept in the session
- `Ctrl+Shift+T` reopens the last closed tab at the same cursor position
- The active tab is always visible in the tab bar, with `‹N` / `+N` for hidden tabs on either side; very long names are shortened
- Double-click selects a word, triple-click a line
- Matching brackets `()` `[]` `{}` are boxed, with the search capped at 64 KiB each way
- The current line is faintly highlighted
- Pytte now has its own icon in the title bar, taskbar and Explorer
