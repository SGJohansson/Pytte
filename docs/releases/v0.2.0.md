Line numbers, search and line operations, all without blocking the UI thread.

- Line numbers from a line index counted in the background: exact on the first frame for ordinary files, `~` with progress in the status bar while a large one is indexed
- `Ctrl+F` search as you type, on a cancellable worker thread with matches highlighted; `F3` / `Shift+F3`, `Alt+C` for case, Swedish letters folded correctly
- `Ctrl+G` go to line
- Line operations: `Ctrl+D` duplicate, `Alt+↑` / `Alt+↓` move, `Ctrl+Shift+K` delete, each a single undo step
- New status bar: saved/changed badge, line and column, line count, selection, line endings and size; nothing is ever drawn on top of text
- Faster line navigation: line starts are found through the line index and SIMD scanning instead of walking byte by byte, so huge single-line files scroll far more smoothly
