Spell checking with Windows' own checker, and new lines that fill the window as they should.

- Spell checking uses the dictionaries and languages already installed in Windows: your locale, keyboard languages and display language (up to three). A word is flagged only if it is wrong in all of them, so mixed Swedish and English text does not light up
- Only text you type or paste is checked, on its own thread; existing text is never scanned, so the cost has nothing to do with the file's size. Large pastes are checked at the start and the end
- Misspelled words get a wavy underline drawn beneath the text, never over it. The word you are still typing waits until you move on
- Right-click a misspelled word for suggestions, *Add to dictionary* (Windows' own user dictionary) or *Ignore* (for this session); the menu follows Windows' dark mode
- `F7` turns spell checking on and off; the status bar shows the state and languages, e.g. `STAV SV+EN`
- Fix: pressing `Enter` at the start of the top visible line, which is where the cursor is in a new document, scrolled the view down with it, so only the last line was visible. Text inserted at the top of the view now stays in view
